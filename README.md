# Flutter Coffee Records — Firebase Integration

This project implements a simple Coffee Records app connected to Firestore.

## What I did
- Connected Android app to Firebase using `android/app/google-services.json`.
- Added `lib/firebase_options.dart` and updated `lib/main.dart` to initialize Firebase.
- Implemented Firestore-backed CRUD with real-time updates using `StreamBuilder`.

## How to run (Windows)
1. Install dependencies and analyze:
```bash
flutter pub get
flutter analyze
```
2. Run on the Android emulator (or a connected device):
```bash
flutter run -d emulator-5554
```

If you prefer the release APK:
```bash
flutter build apk
```

## How to test CRUD (manual)
1. Launch the app and tap **Order Now** or the **+** button.
2. Fill the form and save — the new record should appear in the list.
3. Tap a record to edit it and save changes.
4. Use the delete icon to remove a record.
5. Open the Firebase Console → Firestore and confirm the `coffee_records` collection shows the same documents.
